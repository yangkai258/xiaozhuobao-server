CHAPTER · 00

把对话放回销售日常

销售一天的事不再被 8 个表单瓜分，而是从一句开场白开始：拍照建档、问业绩、查库存、补资质、补提交。AI 成为外壳，业务接口是内核。

核心动作
· 拍照客户营业执照 → 自动建客商草稿 → 进入编辑态补字段 → 提交审批
· 口述"上海建工近 30 天业绩" → 调接口取数据 → AI 摘要 + 列表下钻
· 粘贴技术参数 / 上传 PDF → 知识库检索 → 出处段落 + 跳转业务单
· 提问跟进 / 售后 / 订单状态 → 调业务接口 → 1 张卡片代替 3 次跳转
位置
中间 tab（midButton）天然适合"对话"作为统一入口；其它 4 tab（工作台 / 资讯 / 订单 / 我的）保留。
